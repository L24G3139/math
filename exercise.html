・接線⊥半径 （∠PSO = ∠PTO = 90°）

・OP = OP （共通）

　△POS ≡ △POT  ⟹  PS = PT

問題⑥ 円周角の定理の証明（∠ACB = ½∠AOB）
ヒント：C から直径 CD を引き、△OAC と △OBC の二等辺三角形を利用する
① C を通る直径 CD を引く（Oを挟んでCの反対の点をDとする）
② \(OA = OC\)（半径）より \(\triangle OAC\) は  …(1)
③ \(\angle OCA = \angle OAC = \alpha\) とおくと、
△OACの外角より  \(\angle AOD =\)  …(2)
④ 同様に \(OB = OC\)（半径）より \(\angle OCB = \angle OBC = \beta\) とおくと
\(\angle BOD =\)  …(3)
⑤ \(\angle ACB = \alpha + \beta\) かつ
\(\angle AOB = \angle AOD + \angle BOD =\) \(= 2\angle ACB\) …(4)
⑥ (4)より  \(\angle ACB = \dfrac{1}{\,\) \(\,}\angle AOB\)  （証明終）
【定理】
円Oにおいて、弧ABに対する円周角\(\angle ACB\)は中心角\(\angle AOB\)の半分、 すなわち \(\angle ACB = \dfrac{1}{2}\angle AOB\) であることを証明せよ。
（OがACBの内部にある場合を証明せよ。）

模範解答
C を通る直径 CD を引く（O の反対側の点を D とする）。
\(OA = OC\)（半径）より \(\triangle OAC\) は二等辺三角形だから
 \(\angle OCA = \angle OAC\) これを \(\alpha\) とおく。
\(\triangle OAC\) の外角より \(\angle AOD = 2\alpha\) …(1)
\(OB = OC\)（半径）より \(\triangle OBC\) は二等辺三角形だから
 \(\angle OCB = \angle OBC\) これを \(\beta\) とおく。
\(\triangle OBC\) の外角より \(\angle BOD = 2\beta\) …(2)
(1)(2)より \(\angle AOB = \angle AOD + \angle BOD = 2\alpha + 2\beta\)
一方 \(\angle ACB = \angle OCA + \angle OCB = \alpha + \beta\)
したがって \(\angle AOB = 2\angle ACB\)、
すなわち \(\angle ACB = \dfrac{1}{2}\angle AOB\) （証明終）
